# 📉 Unemployment Analysis in India

## 📌 Project Overview

This project analyzes unemployment trends in India using Python. It explores unemployment rates across different states and studies the impact of COVID-19.

## 🎯 Objectives

- Clean the dataset
- Perform Exploratory Data Analysis (EDA)
- Visualize unemployment trends
- Analyze COVID-19 impact
- Generate meaningful insights

## 📂 Dataset

Unemployment in India Dataset (Kaggle)

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Visualizations

- Heatmap
- Bar Chart
- Line Plot
- Pie Chart
- Box Plot
- Scatter Plot

## 📈 Insights

- State-wise unemployment rate
- Monthly unemployment trend
- COVID-19 impact
- Correlation analysis

## 🚀 How to Run

```bash
pip install -r requirements.txt
```

```bash
jupyter notebook unemployment_analysis.ipynb
```
