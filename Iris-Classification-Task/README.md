# 🌸 Iris Flower Classification

## 📌 Project Overview
This project builds a Machine Learning classification model to identify the species of Iris flowers using their measurements.

## 🎯 Objective
- Classify Iris flowers into:
  - Setosa
  - Versicolor
  - Virginica
- Learn data preprocessing and classification techniques.

## 📂 Dataset
Scikit-learn Iris Dataset

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 📊 Workflow
1. Import Dataset
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Prediction
6. Model Evaluation

## 🤖 Machine Learning Algorithm
- Random Forest Classifier

## 📈 Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Classification Report

## 📷 Output
- Species Prediction
- Accuracy Score
- Confusion Matrix
